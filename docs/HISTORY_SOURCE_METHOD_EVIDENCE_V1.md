# Historie — kildeformfamilier evidens V1

Fasen etablerer claim–source–case-grunnlag for visuelle kilder, muntlige kilder, serielle kilder, dokumentautentisitet og arkeologisk kontekst/formation.

- Nye claims: **17**
- Nye kilder: **13**
- Nye evidenskoblinger: **17**
- Nyvaliderte cases: **Meteorologisk institutt** og **Middelalderbyen Oslo**
- Kvalifiserte teoriobjekter: **5**

Institusjonell oppbevaring eller generisk kildebruk er ikke metodebevis. Hver bane dokumenterer produksjon, proveniens eller formation, utvalg, metadata og kildeformspesifikke begrensninger. Muntlig historie er kvalifisert gjennom intervju- og erindringsclaims uten å opprette et kunstig emne-ID.
