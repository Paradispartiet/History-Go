## Dekning

Start med [rollemodellmanifestet](../data/Civication/roleModels/manifest.json) for registrerte rollemodeller, [rolleverdener](../data/Civication/roleWorlds/) for egne livsposisjoner og [synopsismatrisen](CIVICATION_BOOK_FILM_STORY_MATRIX_V1.md) for private roller og relasjoner. Sjekk identitet før opprettelse, slik at gamle filnavn og aliaser går til riktig profil. Del beskrivelser av felles praksis via lenker, og gi hver rolle sitt eget ansvar, handlingsrom og særpreg. En rolle uten oppføring over mangler en gjennomgått profil i dette registeret. Profildekning føres separat fra spillbarhet.

## Hva hver profil skal dekke

| Del | Hva forfatteren må kunne slå opp |
| --- | --- |
| Rolle og ansvar | Arbeidsbeskrivelse eller relasjon, hvor den utøves, hvem rollen svarer til, hva personen kan bestemme, hvem som må overta og hvilke lokale varianter som finnes. |
| Titler og ordliste | Skill mellom faktiske synonymer, søkeord, fagtermer, lokale uttrykk, spesialiseringer og nabostillinger. Forklar begrepet gjennom bruken. |
| Utstyr, klær, steder og dokumenter | Hva personen bruker eller håndterer, hva som er påkrevd, hva som er lokalt, og hvor ting finnes. For private roller kan dette være meldinger, et møtested, en delt nøkkel eller en gjenstand folk har avtalt å levere. |
| Klasse, vilkår og makt | Yrkesgruppe der den er relevant, ansettelse eller oppdragsform, kvalifikasjoner, arbeidstid, inntektssikkerhet, fysisk belastning, status og hvem som faktisk rår over tid, penger, tilgang og beslutninger. Beskriv forholdene konkret og individuelt. |
| Oppgaver og vanlige forløp | Vanlig vakt eller samhandling før noe går galt. Oppgi utløsende behov, rekkefølge, materiell, leveranse og overlevering. |
| Hendelser, problemer, konflikter og handlingsrom | Skill mellom det personen ser og det hen antar. Oppgi hva partene prøver å få gjort, flere realistiske svar, hva de koster, hva som må løftes videre, og hva som faktisk kan få følger. |
| Kilder, synopsis og kontinuitet | Oppgi hva kildene dekker og hva som er redaksjonelt konkretisert. Lenke videre til rollemodell, arbeidsgrammatikk, kildeanalyse eller synopsis og eksisterende spillforløp når de finnes. |

Sjekk en yrkesbeskrivelse eller fagkilde og minst to relevante arbeidsgiver- eller praksiskilder der de finnes. Registrer arbeidssted eller sektor, hvilken påstand kilden dekker og datoen den ble sjekket. For livsposisjoner og private roller brukes relevante fagkilder, undersøkelser eller dokumenterte praksiseksempler. Marker hva som er lokal praksis, hva som er et forslag til spillverdenen, og hva som fortsatt mangler belegg. I en privat rolle kan yrkesgruppe og arbeidstøy falle bort. Undersøk hvilke materielle og sosiale vilkår som faktisk betyr noe i situasjonen.

## Slik brukes dokumentene sammen

1. **Rolleprofilen** eier beskrivelsen av hverdagen og kildene. Arbeidsgrammatikken eller rollemodellen eier de strukturerte reglene og oppgavene som allerede finnes.
2. **Synopsis** lenker til berørte profiler og eier hovedforløpet, rollefigurenes ulike mål og scenenes valg. Flere plausible svar kan gi samme neste hendelse med ulike poeng eller relasjonsspor. Forgren når en konkret avtale, leveranse eller relasjon faktisk endres.
3. **Spillforløpet** eier spillbar dialog og konsekvenser. [Spillerens Symposium](CIVICATION_SYMPOSIUM_NARRATIVE_PRINCIPLES.md) viser hendelser, valg og avtaler som faktisk er registrert i spillerens historie.
