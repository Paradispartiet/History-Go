# Fagverk IA v3 — beslutningslogg

## 2026-08-28

1. `view=` forkastes. Eksisterende canonical query-parametere beholdes.
2. Emnerendereren beholdes og løftes frem; det bygges ikke et nytt emnesystem.
3. Fagverksmotoren endres som én delt motor for alle fag; fag brukes som QA-representanter, ikke som separate implementasjoner.
4. Merke beholdes som gameplay/progresjonsidentitet, mens separat merkeside behandles som legacy/compatibility-mål under kontrollert migrering.
5. `emner.html` behandles som personlig progresjonsflate, ikke canonical emnekatalog.
