# Barnebokakademiet

Barnebokakademiet (`hgChildrenLiteratureGame`) er et eget, uavhengig History Go-læringsspill for barnelitteratur og fortellertradisjon. Spillet kan kobles til felles History Go-data, men det skal ikke eies av Civication, og Civication skal ikke være motor, progresjonseier eller datakildeeier for spillet.

## Omfang

Spillet skal håndtere:

- barnebøker
- ungdomsbøker / YA
- barnesanger
- eventyr
- bildebøker
- muntlig fortellertradisjon

Barnebokakademiet kan bruke History Go-steder, personer, verk og oppgaver som referanser og læringsankere. Det skal kunne lese felles samlinger for steder, personer, verk, institusjoner, ruter, merker, objekter og relasjoner, og skrive progresjon, unlocks, merker, steder, personer, verk og poeng tilbake til profilen via History Go-kontrakten.

## Rettigheter og tekstbruk

Spillet kan bruke metadata, titler, forfatternavn, illustratørnavn, historiske fakta, steder, sjangre, motiver, tema og public domain-materiale. Det skal ikke kopiere, importere eller gjengi beskyttet boktekst fra barnebøker, ungdomsbøker, sangtekster, bildebøker eller nyere eventyrsamlinger.

## Forholdet til Skrivekunstakademiet

Goodreads-importer som identifiseres som barnebøker eller YA skal ikke legges i `personalGoodreadsCanon` for Skrivekunstakademiet. De skal rutes til Barnebokakademiet som `childrenLiteratureCanon` eller `pendingChildrenLiteratureCandidates`, uten å lagre rating, private notater eller andre private Goodreads-felt.
