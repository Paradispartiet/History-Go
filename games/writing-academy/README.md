# Skrivekunstakademiet er flyttet

Skrivekunstakademiet (`hgWritingAcademy`) er flyttet til eget repo:

- App og GitHub Pages: <https://paradispartiet.github.io/Skrivekunstakademiet/>
- Repo: `Paradispartiet/Skrivekunstakademiet`

History-Go eier fortsatt canonical litteraturdata: people, places, works, institutions, routes, badges, objects og relations. Skrivekunstakademiet leser disse History-Go-dataene som eksterne referanser, men eier egen app, oppgaver, spor, skriveparametere, matcher-regler og progresjon.

Denne mappen er bare en tynn bro for gamle lenker. Den lokale History-Go-kopien skal ikke fungere som full app eller datakilde for Skrivekunstakademiet.
