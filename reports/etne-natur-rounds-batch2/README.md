# Etne natur – rundingsbatch 2

Komplette naturprofiler for Folgefonna nasjonalpark – Etne, Mosneselva og Rullestadvatnet.

Alle tre følger canonical naturprofil uten manuell rounds-override: tasks, nature, badges, training, civication, brands, før_nå, fortellinger og leksikon.

Kildegrunnlaget er primært NVE, Folgefonna nasjonalpark og Etne kommune. Brede områdeankre behandles som områdeankre, ikke som anbefalte startpunkter. Rullestadvatnet får ingen udokumenterte artskoblinger.
