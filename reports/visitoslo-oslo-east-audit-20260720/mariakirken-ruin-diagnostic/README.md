# Mariakirken-ruinen — Riksantikvaren objektdiagnose

- Søk: eksplisitt CRS84-bbox over Middelalderbyen + CQL2 navnefilterforsøk
- Offisielle identitetskandidater: **90**
- Canonical identitetsmatcher: **1**
- Neste gate: **identity_review**

Denne jobben oppretter ingen place-data. Hvis ett eksakt offisielt objekt identifiseres, skal neste steg være direkte feature-oppslag før koordinaten kan brukes.
