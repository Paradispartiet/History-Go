# History GO — rapportarkiv

Denne mappen inneholder tidsbundne audits, statusrapporter og migreringssnapshots som er bevart for sporbarhet, men som ikke skal brukes som nåstatus eller runtime-kontrakt.

Aktive rapportregler styres av [`../README.md`](../README.md). Aktiv dokumentstatus styres av [`../../docs/documentation_registry.json`](../../docs/documentation_registry.json).

Når en rapport flyttes hit:

- behold den opprinnelige teksten uendret når historisk sporbarhet er viktig,
- registrer snapshotet som `historical` i dokumentregisteret når det inngår i den styrte dokumentkjeden,
- legg igjen en kort peker på gammel kjent path bare når eksisterende lenker eller arbeidsflyt trenger det,
- pek til den aktive erstatningskilden.
