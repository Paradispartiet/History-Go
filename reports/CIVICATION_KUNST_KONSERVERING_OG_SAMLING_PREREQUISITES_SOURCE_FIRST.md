# Civication — Kunst / Konservering og samlingsbevaring prerequisites

This package materializes the playable prerequisite foundation for `kunst/kunst_konservering_og_samling`. It is **not Role World completion** and creates **no new runtime**.

## Existing contracts preserved
- Existing `civication_role_model_v2`, canonical two conservation work loops and exact work-grammar authority boundary remain authoritative.
- Career entry remains title-specific: Konservator is `qualification_required` with `relevant_education_or_employer_qualification`; Senior konservator is `appointment_required` and requires both `relevant_education_or_employer_qualification` and `employer_appointment`.
- History Go is an art-historical and source-critical learning affordance, not condition diagnosis, conservation qualification, appointment, treatment approval, insurance decision, transport approval or ownership authority.

## Eleven readiness gaps
The prerequisite fills day one, functional knowledge, all nine mail types, People, Places, repeatable workday loop, History Go affordance, People/Places integrity, one persistent work object and explicit waiting/handoff/rework. The only Role World-authored debt that should remain is `situated_reputation`.

## Persistent work
`kunstverk_tilstands_material_behandlings_og_utlanslogg` carries object identity/provenance, materials/technique, condition/damage, previous interventions, analysis basis, competence and appointment boundaries, treatment/reversibility, climate, loan/insurance, packing/transport, mounting/display limits, waiting, handoff, ownership of next step and bounded rework.

## People and surfaces
Four current-work actors are fictional scenario actors with `canonical_person_ref: null`. Four work surfaces cover condition/material/treatment, collection registration, loan/transport/climate, and exhibition/mounting.

## Mail and playable day
The role uses 16 deterministic plan steps and **15 source mails** across all nine required types: 4 job, 4 people and one each conflict/story/event/micro/followup/knowledge/consequence. Every step has empty fallback types and every family is role-scoped.

## Fail-closed target
The package is valid only if Role Pack, Scene Registry, Career gameplay, rollout readiness, Scenario People, full Civication, job learning profiles and job knowledge requirements all pass together. Any failure must discard materialized canonical changes and retain only an exact TEMP diagnostic.
