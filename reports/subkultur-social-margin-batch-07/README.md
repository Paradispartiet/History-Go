# Subkultur – sosiale randsoner batch 07

Dato: 2026-07-23

## Lagt til

- `mo_senteret_gyldenpris` – tidligere Strax-huset, Bergen
- `matfellesskap_st_petri_stavanger` – gatenært mat- og møtefellesskap, Stavanger
- `kafe_x_tromso` – brukerstyrt rusfri møteplass, Tromsø

## Faglig avgrensning

Batchen går tilbake til kjernen i History Go sin Subkultur-grense: dokumenterte sosiale randsoner og infrastrukturen mennesker i eller med erfaring fra rus- og gatemiljø bygger eller bruker. Stedene legges ikke inn som generiske helse-, kirke- eller kafétilbud.

MO-senteret Gyldenpris og Matfellesskap St. Petri representerer gatenær lavterskel- og støtteinfrastruktur. Kafe X representerer brukerstyrt, rusfri sosial infrastruktur skapt av mennesker med egne erfaringer fra rusrelaterte utfordringer.

## Redaksjonell QA

- Gyldenpris skilles tydelig mellom aktivt rusmiljø, sosialt møtepunkt, skadereduksjon og kommunal tjeneste.
- St. Petri beskrives som mat- og møtefellesskap for rus- og gatemiljøet, ikke som et generisk kirkested.
- Kafe X beskrives eksplisitt som rusfri og brukerstyrt, og skal ikke framstilles som en aktiv russcene.
- Canonical markører følger Geonorges eksakte adresseobjekter; eksterne kilders eventuelle postnummerformatering overstyrer ikke det verifiserte adresseobjektet.

## Datakvalitet

- mennesker beskrives som mennesker, ikke som problemer eller kulisse
- rus og marginalisering romantiseres ikke
- skillet mellom aktivt rusmiljø, skadereduksjon, matfellesskap og recovery beholdes
- alle koordinater hentes address-first fra dokumenterte besøksadresser og rå Geonorge-evidens lagres i rapportmappen
