# Scenekunst — Dramaturgi og utvikling prerequisites source-first

This change materializes the playable career foundation for `scenekunst/scenekunst_dramaturgi_og_utvikling`. It is prerequisite work, not Role World completion.

The foundation follows one versioned `dramaturgisk_arbeidsbok` through source review, structural diagnosis, artistic disagreement, rehearsal observation, rights clarification, handoff, rework and a documented production decision. Four explicitly fictional current-work actors inhabit four fictional work surfaces. They are scenario actors only and must never enter factual History Go People.

The existing Scenekunst career evidence remains authoritative: Badge progress does not prove employment, Dramaturg remains appointment-gated, and the existing work loops, five practice stories, quality axes and authority limits are preserved. The playable layer adds a 16-step plan using all nine mail types, 15 role-specific scenes and no generic fallback families.

History Go is bounded to a concrete learning task about Johanne Dybwad and Nationaltheatret. That task can sharpen questions about performance history, interpretation, institutional context and source limits; it cannot grant adaptation rights, artistic mandate, programming authority, budget authority or permission to present a research hypothesis as fact.

The prerequisite package must prove a persistent work object, explicit waiting/handoff/rework rhythm, people/place integrity, playable day one, consequences, performance, progression and exit. Situated standing signals belong to the authored foundation, but `role_world_status` must remain `role_world_not_started`; the later dedicated Role World PR remains responsible for the full 14-day, 56-beat world.

Cross-role work is `not_required_for_rollout`. No shared object, new runtime or global reputation score may be invented.
