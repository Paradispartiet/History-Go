# Oslo coordinate control batch 33

Kontrollerer manifestrekkefølge 7–13 i Akerselva-ruten. To records bruker entydige Geonorge-adressepunkter, fire bruker eksakte navngitte OSM-objekter, og Vøyenfallene beholdes eksplisitt uverifisert til fallrekken har stabil fleranker-/geometrimodell. Split-innholdet bevares; bare koordinatfeltene synkroniseres.
