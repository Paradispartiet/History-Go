# Vikedalsvassdraget – Bjønndalen: natur-rundinger batch 1

Denne produksjonsbatchen er replayet fra validert commit `28f788d6dd5e17f78904d86e83f4562238ff51b3` på eksakt fersk main-base `315f051706c2ba4dab00ab240d5725f129224ef6`.

Den legger inn det siste systematiske Etne-naturstedet og starter rundingsproduksjonen med alle ni canonical natur-rundinger uten manuell `rounds`-override.

Kildene i selve steds-, fortellings- og leksikondataene er NVE, Etne kommune og Miljødirektoratet. Bjønndalen behandles som Etne-anker for et større vassdrag, ikke som hele Vikedalsvassdraget.
