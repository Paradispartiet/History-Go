# Civication — Subkultur / Program og koordinering prerequisites

This package materializes the playable prerequisite foundation for `subkultur_program_og_koordinering`. It is **not Role World completion** and does not add new runtime state.

## Source-first scope
- Existing canonical role model and work grammar are extended rather than replaced.
- Persistent work object: `programbok_booking_budsjett_avtale_og_publiseringslogg`.
- Four fictional scenario actors: booking/artist contact, economy/contracts, local scene/partners, communication/publication.
- Four role-owned work surfaces keep criteria, booking/contract/cost, partner representation and publication/logistics separate but version-connected.
- 15 authored mails across all 9 canonical mail types; deterministic 16-step plan; no generic fallback.
- History Go: Club 7 / `club_7_vika` is a bounded historical program-and-milieu affordance only. It cannot prescribe current booking, grant program entitlement, approve fee/contract/rights, set capacity or create safety authority.
- Cross-role remains `candidate_when_shared_work_is_real`; no shared work object or cross-role runtime is materialized merely because producer, production lead or arena roles are plausible collaborators.

## Authority
Program coordination may compare alternatives, coordinate offers and hold publication when prerequisites are missing. It may not promise booking/program place without mandate, hide real cost or expected unpaid work, use subcultural status/friendship as access criteria, publish unresolved status as confirmed, or invent legal/rights/economic/employer/safety authority.

29/30 before PR browser boot. The final point is reserved for exact-head Chromium boot/typecheck CI.
