# Religion / Utredning og rådgivning — Role World rollout source-first

## Scope lock
Denne pakken materialiserer bare canonical `religion/religion_utredning_og_radgivning`. Fagkonsulent og Seniorrådgiver beholder **direct** career-entry. Ingen ny runtime, ingen parallell sceneformat og ingen ny rolleidentitet opprettes.

## Existing foundation preserved
Den eksisterende 16-stegs mailplanen, fire fiktive scenarioaktører, fire arbeidsflater, work loops og `utredningslogg_bestilling_kilder_aktorer_rettigheter_analyse_anbefaling_beslutning_og_oppfolging` er bevart. Role World-en forfatter bare **situated_reputation** som manglet i readiness.

## Standing og authority
Det finnes **No global reputation score**. Standing er situert hos syv separate publikum og kan påvirke tillit, tone, samarbeid og oppfølging. Standing kan aldri erstatte evidens, delegasjon, juridisk kompetanse, representasjonsmandat eller faktisk beslutningseier. Seniorrådgiver-tittel gir ikke skjult authority.

## History Go
History Go og Religion-badge kan forbedre historiske spørsmål, kronologi og kildekritikk. De kan ikke være dagens evidens, gi vedtaksmyndighet eller gjøre én tros-/livssynsaktør representativ.

## Materialization proof
Alle **15 canonical** prerequisite-mails brukes som materialization refs. Sesongen er **14 days × 4 phases = 56** unike beats, syv hovedtråder, minst seks private aftermaths og åtte delayed consequences. Hver canonical mailreferanse brukes minst tre ganger.

## Cross-role
Cross-role-status er **not_required_for_rollout**. Det er ikke funnet et genuint delt work object som må materialiseres for denne rollen.

## Editorial uniqueness
Dramaturgien er skrevet særskilt for religionsfaglig utredning: bestillerpress, kilde- og aktørasymmetri, rettighets- og jussgrenser, skillet mellom råd og beslutning, senioritet som uformell makt, offentlig etterprøvbarhet og korrigerbar handoff. Den kopierer ikke plot, figurer eller dialog fra en reference Role World.
