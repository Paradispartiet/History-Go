# Øvre Spinneri – Matrikkelen Bygningspunkt research

Research-only correlation of OSM candidate building numbers with Kartverket's open Matrikkelen Bygningspunkt WFS.

- WFS feature type: `app:Bygning`
- Candidate OSM building numbers: 81764387, 300171619
- Exact WFS building-number matches: 2

For each candidate the report stores CQL and FES-filter responses in standard GML, including official building point, status and culture/SEFRAK flags when returned. No canonical coordinates are changed by this job.
