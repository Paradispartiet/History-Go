# Etne natur – rundingsproduksjon batch 8

Komplette naturprofiler for Taraldsøy, Brattholmen naturreservat og Skåno naturreservat. Taraldsøy behandles som friluftsøy, Brattholmen som liten sjøfuglholm med marint ferdselsbelte, og Skåno som større sjøfuglreservat der tradisjonell beiting er en eksplisitt del av vernebildet.
