# Subkultur / Produksjonsledelse — prerequisite source-first

Dette er **not Role World completion**. Leveransen materialiserer bare prerequisite-laget som gjør rollen trygg nok til en separat Role World-rollout.

## Kilde og rollegrense

- Canonical role scope: `subkultur/subkultur_produksjonsledelse` / role id `subkultur_produksjonsledelse`.
- Eksisterende role model/work grammar er utvidet, ikke erstattet av ny runtime.
- Persistent work object: `produksjonsbok_kjoreplan_bemanning_sikkerhet_og_avvikslogg`.
- Cross-role: `candidate_when_shared_work_is_real`; plausible delte flater finnes mot produsent/program, men ingen shared runtime eller shared work object materialiseres før samme arbeid faktisk er bevist delt.
- History Go-affordance bruker `club_7_vika` som historisk refleksjonsanker for operative avhengigheter, aldri som fasit for dagens HMS, brann-/kapasitetskrav, bemanning, arbeidstid, kommandolinje eller frigivelsesmyndighet.

## Materialisert prerequisite-dybde

- første dag og 16-stegs mailplan
- fire eksplisitt fiktive arbeidsaktører og fire rolle-eide arbeidsflater
- ni mailtyper / 15 mails uten generisk fallback
- produksjonsbok med waiting/venting, handoff, stoppeier, bounded rework og retest
- kjøreplan/cue, kvalifisert bemanning, skift/hvile, teknisk frigivelse, husdrift, sikkerhet, publikumsflyt, avvik og debrief
- situert standing uten global score eller myndighetslekkasje
- eksplisitt skille mellom produksjonslederens operative koordinering og formell HMS/sikkerhet, arbeidsgiveransvar, teknisk fagmyndighet, medisinsk/juridisk myndighet og rettighets-/ansettelsesbeslutninger

## Kvalitetsport

Intern prerequisite-vurdering: **29/30**. Det ene bevisst holdte punktet er cross-role-materialisering: plausible delte flater finnes mot Produksjon og prosjekt og Program/koordinering, men kobles ikke før et faktisk delt arbeidsobjekt og distinkte myndighetslinser er bevist.
