# Oslo koordinatkontroll – batch 40 research

Dato: 2026-07-20

Ruters gjeldende rutetabell fra 20. april 2026 dokumenterer linje 17 som Gaustadalléen–Sinsen–Grefsen stasjon og linje 18 som Gaustadalléen–Storo–Grefsen stasjon. Combined-recorden vurderes som et forgrenet rutepar, ikke ett symbolsk midtpunkt.

Ankerresearch bruker Enturs nasjonale stoppregister via Geocoder API. Bare eksakt navnematch vurderes; ett entydig trikkerelevant stopp foretrekkes, ellers ett entydig NSR StopPlace. Ingen nærmeste- eller første-treff-gjetting er tillatt.
