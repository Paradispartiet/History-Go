# Civication — Historie / Museum og samling prerequisites

This package materializes the playable prerequisite foundation for `historie/historie_museum_og_samling`. It is **not Role World completion** and creates **no new runtime**.

## Existing contracts preserved
- Existing `civication_role_model_v2`, canonical two work loops and exact authority boundary remain authoritative.
- Career entry is title-specific, not flattened: Konservator and Senior konservator remain `qualification_required` with `relevant_education_or_employer_qualification`; Kurator and Senior kurator remain `direct`.
- History Go is a source-critical learning affordance, not conservation qualification, provenance authentication, treatment approval, ownership/restitution authority, rights clearance or a mechanism for turning curatorial interpretation into source fact.

## Eleven readiness gaps
The prerequisite fills day one, functional knowledge, all nine mail types, People, Places, repeatable workday loop, History Go affordance, People/Places integrity, one persistent work object and explicit waiting/handoff/rework. The only Role World-authored debt that should remain is `situated_reputation`.

## Persistent work
`samlingsobjekt_proveniens_tilstands_og_tiltakslogg` carries object identity, provenance/ownership history, condition, prior interventions, competence and treatment boundaries, sources and curatorial interpretation, representation/rights/restitution signals, waiting, handoff, ownership of next step and bounded rework.

## People and surfaces
Four current-work actors are fictional scenario actors with `canonical_person_ref: null`. Four work surfaces cover intake/provenance, condition/conservation, curation/exhibition, and representation/restitution/public response.

## Mail and playable day
The role uses 16 deterministic plan steps and **15 source mails** across all nine required types: 4 job, 4 people and one each conflict/story/event/micro/followup/knowledge/consequence. Every step has empty fallback types and every family is role-scoped.

## Fail-closed target
The package is valid only if Role Pack, Scene Registry, Career gameplay, rollout readiness, Scenario People, full Civication, job learning profiles and job knowledge requirements all pass together. Any failure must discard materialized canonical changes and retain only an exact TEMP diagnostic.
