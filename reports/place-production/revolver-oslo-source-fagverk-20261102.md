# Revolver Oslo – kildebasert stedshistorie og Fagverk (2026-11-02)

## Identitet
- Canonical ID: `revolver_oslo` (bevart).
- Canonical kilde: `data/places/subkultur/oslo/places_subkultur/revolver_oslo.json` (filbanen beholdes; selve kategorien er `musikk`).
- Offisiell adresseregistrering: Møllergata 32B, 0179 Oslo; arrangørens besøksadresse markedsføres som Møllergata 32. Geonorge-punkt og alle koordinatfelter er urørt.
- Primærkategori Musikk; sekundærmerke Subkultur; år 2007.

## Produsert
- Historisk ingress og fem selvstendige stedstekstavsnitt inkludert festivalhistorie fra Ballade, uten spillintern tekst.
- Eget kuratert Fagverk med tre artikler, tre undersøkelser, kildehenvisninger og eksisterende musikkapitler.
- Canonical Fagverk-indeks og Place-open synkronisert i denne arbeidsgrenen.
- Ingen endringer i eksisterende kollektiv People-ID, koordinater, sekundærmerker eller andre steder.
