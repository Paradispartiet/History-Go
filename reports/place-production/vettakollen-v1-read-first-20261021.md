# Vettakollen – History Go v1 kildepakke, 21.10.2026

## Stedsidentitet
Canonical ID `vettakollen`, OSM peak node osm-node:301173327, uendret toppkoordinat 59.9765497, 10.6990279. Boligstrøket og stasjonen er egne objekter. Høyden oppgis 418 meter av Oslo byleksikon og 419 meter av SNL; den berømte sørlige utsikten ligger på rundt 378 meter. Ikke bland punktene.

## Historisk fortelling
Gammel vardeplass med usikker startdatering; kobberskjerp øst for Båntjern 1704–1714; Holmenkollbanen fra 1898 og stasjon opprinnelig Greveveien; stasjonsbygning 1907; postkontor til 1989; stier til Fuglemyra og Fuglemyrhytta (2018). Opplysningene om mulig bronsealderdyrking ved Fuglemyra er usikre.
