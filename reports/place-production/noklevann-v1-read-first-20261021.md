# Nøklevann – v1 nullmåling, historisk produksjonsfase 21.10.2026

## Identitet
Eksisterende kanonisk `noklevann`, `data/places/natur/oslo/places_oslo_natur_hovedsteder/noklevann.json`. Kartposisjon, koordinatrolle, kategori `natur`, underbadges og eksisterende naturprofil er beholdt. Sarabråten, Bremsrud og Rustadsaga er tilgrensende historiske steder, ikke alternative identiteter for innsjøen.

## Førstatus
`desc` og `popupDesc` var korte og beskrev produksjonsinstrukser («I History Go bør ...»). Ingen egen kuratert Fagverk-side, ingen aktiv fullquiz for `noklevann`, ingen registrert natur-QuizCard og ingen lokale stedbilder ble funnet. Årsverdien 1923 er foreløpig beholdt uten å tolke den som anleggsår for demningen.

## Status etter første innholdscommit
Historisk `desc` og `popupDesc` er produsert og en egen Fagverk-side på `standard/curated` registrert. **Dette er ikke ferdig v1.** Følgende gjenstår: fullquiz i gyldig adaptiv profil med kilde- og Knowledge-koblinger, QuizCard med ti like spørsmål, kildebasert description v4.2-pakke, lokale WebP-bilder, genererte indekser/Place-open, ordinær CI og reell mobil-/desktop-kontroll. Bildesøk er avgrenset til eksisterende CC BY-SA 3.0-kilder fra Kjetil Ree; ingen rettighetsforespørsler.
