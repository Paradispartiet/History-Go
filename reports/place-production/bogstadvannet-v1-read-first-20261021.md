# Bogstadvannet – v1 READ-FIRST, 21.10.2026

## Avgrensning
Stedet er selve innsjøen Bogstadvannet mellom Oslo og Bærum, ikke Bogstad gård, Bogstaddammen eller en bestemt badeplass. Canonical kildefil: `data/places/natur/oslo/places_natur/bogstadvannet.json`. Eksisterende kartanker, OSM-way 4351126 og naturprofilens merke- og emnebindinger er bevart.

## Kilde- og fortellingsplan
Vannsystem: Sørkedalselva → Bogstadvannet → Lysakerelva. Mindre tilløp: Åborbekken og Jegersborgbekken. Se https://oslobyleksikon.no/side/Bogstadvannet og https://snl.no/Bogstadvannet.
Tidligere navn: Fåd-/Fåvannet. Tømmerfløting gjennom Sørkedalen og roing av stokker over Bogstadvannet, se https://lokalhistoriewiki.no/Bogstadvannet og https://lokalhistoriewiki.no/Lysakervassdraget.
Vannregulering: Osdammen og økt vannstand rundt 1869, Øvre Fossum sag/Ossaga 1870–1913, steindemning 1913, se https://lokalhistoriewiki.no/Bogstadvannet. Gårds- og skogbrukskontekst: https://bogstad.no/bogstads-historie.
Fritidslandskap: isuttak ved Voksen gård fram til 1930-årene, golfbane 1924, campingplass 1959; Christiania Roklub, strender, naturkant, se https://lokalhistoriewiki.no/Bogstadvannet, https://snl.no/Bogstadvannet.
Redaksjonell grense: ingen udokumenterte personscener, ingen antatt gjeldende badevannsgaranti, ingen forveksling med bygningene på Bogstad gård.
