# Sport – tidligere regler for antall sett

**Status: utgått som styringsdokument.**

Antall sett skal ikke styres av en separat Sport-regel. Alle kategorier følger kuttregelen og den adaptive størrelsen i:

`data/quiz/regler/QUIZ_PRODUCTION_CANONICAL.md`

Sportens faglige prioriteringer ligger i:

`data/fag/sport/supersetQUIZMAL_sport.json`

Quizen skal være så lang som det finnes sterkt, verifiserbart og variert stoff til — ikke fylles med emneparafraser for å nå et bestemt settnivå.
