# Subkultur – tidligere set-mal

**Status: utgått som selvstendig quiz-styringsdokument.**

Denne filen beholdes for historikk, men peker på de gjeldende styringsfilene for Subkultur.

Gjeldende filer er:

1. `data/quiz/regler/QUIZ_PRODUCTION_CANONICAL.md` – eneste bindende produksjonsprosedyre
2. `data/quiz/regler/QUIZ_QUESTION_SCHEMA_V2.json` – teknisk spørsmålsskjema
3. `data/fag/subkultur/SUBKULTUR_CATEGORY_BOUNDARY.md` – bindende redaksjonell kategorigrense for hva som hører til Subkultur
4. `data/fag/subkultur/supersetQUIZMAL_subkultur.json` – Subkultur-fagets prioriteringer, begreper, kildetyper og kategoriinnhold

Den gamle generatorpatchen er ikke en autoritet. Ved konflikt om quizstruktur gjelder den kanoniske produksjonsfilen. Ved konflikt om hva som faktisk hører til kategorien Subkultur, gjelder `SUBKULTUR_CATEGORY_BOUNDARY.md`.
