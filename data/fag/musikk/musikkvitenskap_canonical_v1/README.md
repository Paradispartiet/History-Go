# Musikkvitenskap canonical v1

Denne katalogen er den vitenskapelige autoriteten for nye musikkfaglige emner, metoder og spørsmålsplaner i History Go.

Pakken beskriver musikkvitenskap som forskningsfelt. Den er ikke en studieplan og skal ikke inneholde studiepoeng, semestre, arbeidskrav eller eksamensopplegg.

Start i `index.json`. Alle referanser er relative til denne katalogen.

Fagdybdelaget består av:
- `disciplinary_architecture_v1.json`
- `method_protocols_v1.json`
- `theory_and_debates_v1.json`
- `scholarly_source_standard_v1.json`

Revisjon: `musikkvitenskap-fagdybde-v1-2026-07-27`
