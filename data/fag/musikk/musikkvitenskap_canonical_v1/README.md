# Musikkvitenskap canonical v1

Denne katalogen er den vitenskapelige autoriteten for nye musikkfaglige emner, metoder og spørsmålsplaner i History Go.

Start i `index.json`. Alle referanser er relative til denne katalogen.

Den vitenskapelige kjernen består av åtte domener. `university_v1/index.json` legger over en eksplisitt universitetsramme med 180 studiepoeng, NKR 6.2-mål, programlæringsutbytter, emneprogresjon, vurdering, akademisk skriving og kvalitetssikring.

Universitetsrammen er en intern faglig modell, ikke en akkreditert grad eller institusjonell studieplan.

Revisjon: `musikk-university-framework-v1-2026-07-27`
